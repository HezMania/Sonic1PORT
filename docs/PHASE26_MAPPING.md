# Phase 26 source mapping — REV01 SYZ deformation / Labyrinth handoff

Phase 26 is the transition from Spring Yard fidelity work into Labyrinth Zone.  It keeps Phase 25 gameplay fixes intact, replaces Spring Yard's simplified whole-plane parallax with the REV01 horizontal-scroll bands, and establishes Labyrinth's source background path without claiming its water/gameplay systems are complete.

## Spring Yard — REV01 `Deform_SYZ`

Source:
- `_inc/DeformLayers (REV01).asm` — `Deform_SYZ`, `BGScroll_X`
- `levels/syzbg (REV01).bin`

Vertical background motion remains source `$30/$100`, i.e. **3/16 (18.75%)** of foreground camera Y movement.

REV01 then builds a 33-entry horizontal scroll buffer, one value per 16-pixel band:

- rows 0–7 — clouds, beginning at 1/2 foreground X and reducing foreground contribution by 7/128 per row;
- rows 8–12 — mountains at 1/8 foreground X;
- rows 13–18 — buildings at 1/4 foreground X;
- rows 19–32 — bushes, beginning at 1/2 foreground X and increasing by 1/28 per row.

The native renderer now rasterizes the supplied SYZ background layout/chunks once into a repeatable source-plane texture, then displays only the visible 16-pixel strips.  Each visible strip selects its own REV01 X source position while Y uses the original 3/16 relationship.  This replaces Phase 24/25's single 50%-X background-plane approximation.

For an example foreground X of 1024, the source-X magnitudes generated by the native rational formulas are:

- cloud rows: 512, 456, 400, 344, 288, 232, 176, 120;
- mountain rows: 128;
- building rows: 256;
- bush rows: 512, 548, 585, 621, 658, 694, 731, 768, 804, 841, 877, 914, 950, 987 (integer-truncated per row in runtime).

## Labyrinth Zone — initial native background path

Source:
- `_inc/DeformLayers (REV01).asm` — `Deform_LZ`
- `levels/lzbg.bin`
- `palette/Labyrinth Zone.bin`
- `artnem/8x8 - LZ.nem`
- `map16/LZ.eni`
- `map256/LZ.kos`
- `collide/LZ.bin`

The base REV01 Labyrinth background calls `BGScroll_XY` with `$80/$100` camera deltas on both axes, so Phase 26 adds a dedicated `background_mode = "lz"` using **1/2 X and 1/2 Y** parallax.

REV01 additionally applies separate foreground/background ripple tables only at and below `v_waterpos1`.  Phase 26 deliberately does **not** fake that effect yet: the native water height, underwater state, drowning timer, bubbles and related LZ dynamic events need to exist first so the ripple begins at the correct world-space waterline.

## Deferred Spring Yard item

SYZ3's dedicated boss (`$75`) and boss-block (`$76`) dynamic event are still deferred.  The REV01 event spawns the block row near camera X `$2AC0`, then locks the arena and spawns the eight-hit Spring Yard boss at `$2C00`.  Phase 26 does not hold the Labyrinth handoff behind that remaining boss-fidelity item.
