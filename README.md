# Sonic 1 PC Native Godot Port

This is an experimental port of Sonic 1 and 2 to Godot using mostly AI. I have made minimal edits to this as a test to see how good/bad the process was.

HOTKEYS BELOW:

K - This will switch physics mode to Sonic 2 Beta.
L - Swaps between Sonic 1/2b/2 Sprites.
H - Starts a Sonic 2 game placing you in Emerald Hill Zone.
